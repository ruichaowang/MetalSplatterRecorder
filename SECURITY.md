# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, report it via GitHub's [private vulnerability reporting](https://github.com/ruichaowang/MetalSplatterRecorder/security/advisories/new) or email the maintainer directly.

## Scope

This policy covers the code in this repository, including:

- The MetalSplatter rendering library
- PLYIO and SplatIO parsers (file format parsing is a common attack surface)
- The SplatRecorder macOS app
- CI and build infrastructure

## Supported versions

Only the latest commit on the `main` branch is supported.
